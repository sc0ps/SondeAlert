# Support

Thank you for using SondeAlert.

If you need help, have questions or would like to report a problem, please use one of the following options.

---

## Bug Reports

If you have found a bug, please create a new issue using the **Bug Report** template.

Please include:

- SondeAlert version
- Android version
- Device model
- Steps to reproduce the issue
- Screenshots (if available)

Providing detailed information helps resolve issues more quickly.

---

## Feature Requests

Have an idea that could improve SondeAlert?

Open a **Feature Request** and describe:

- The problem you're trying to solve
- Your proposed solution
- Why it would benefit other users

Community suggestions are always welcome.

---

## Questions

For general questions about SondeAlert, please use GitHub Discussions (when available) or check the documentation first.

---

## Response Time

SondeAlert is developed in spare time.

While every effort is made to respond as quickly as possible, response times may vary.

Thank you for your patience and support.

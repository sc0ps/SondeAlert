# Code of Conduct

## Our Community

SondeAlert is built for the worldwide radiosonde community. Whether you are a beginner or an experienced radiosonde hunter, everyone is welcome.

Our goal is to create a friendly, respectful and collaborative environment where users can report issues, suggest improvements and share ideas.

---

## Expected Behaviour

We encourage everyone to:

- Be respectful and considerate towards others.
- Provide constructive feedback.
- Help create a welcoming environment for all users.
- Report bugs and issues clearly and honestly.
- Respect different opinions and experiences.
- Keep discussions focused on SondeAlert and radiosonde recovery.

---

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment or personal attacks.
- Discrimination of any kind.
- Offensive or abusive language.
- Spam or advertising unrelated products or services.
- Sharing malicious software or harmful content.
- Publishing private information without permission.
- Deliberately disrupting discussions or issue tracking.

---

## Bug Reports and Feature Requests

When reporting a bug or suggesting a feature:

- Search existing issues first.
- Provide as much relevant information as possible.
- Be patient while waiting for a response.
- Remember that SondeAlert is developed in spare time.

Constructive suggestions are always appreciated.

---

## Source Code

The SondeAlert application is proprietary software.

This repository is intended for documentation, issue tracking and community feedback.

The application source code is not publicly available.

---

## Enforcement

Project maintainers from Sc0ps Owl Designs reserve the right to edit, hide, lock or remove discussions, issues or comments that violate this Code of Conduct.

Repeated violations may result in users being blocked from participating in the repository.

---

## Contact

If you experience behaviour that violates this Code of Conduct, please contact the project maintainer privately.

Contact details will be published before the first public release.

---

Thank you for helping make SondeAlert a welcoming project for the entire radiosonde community.
